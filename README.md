# NajKrajšiPes

Vytvor web stránku s názvom NajkrajsiPes.sk.



Stránka je online súťaž o najkrajšieho psa.



Používatelia môžu:

- prezerať galériu psov

- hlasovať za psov

- komentovať

- registrovať sa

- pridať svojho psa



Profil psa obsahuje:

- fotku psa

- meno psa

- plemeno

- vek

- popis

- počet hlasov

- komentáre

- tlačidlo hlasovať



Registrácia:

- email

- heslo



Monetizácia:

- pridanie psa stojí 1 €

- zvýraznenie psa stojí 2 €

- reklamy na stránke



ADMIN PANEL:



Stránka musí mať skrytý admin panel dostupný iba na /admin.



Admin panel je dostupný iba pre admin účet a bežní používatelia ho nemôžu vidieť.



Admin panel obsahuje:



Dashboard:

- počet používateľov

- počet psov

- počet hlasov

- nové registrácie



Správa používateľov:

- zoznam používateľov

- blokovanie

- vymazanie účtu



Správa psov:

- zoznam všetkých psov

- úprava psa

- vymazanie psa



Správa komentárov:

- moderovanie komentárov

- vymazanie komentárov



Správa platieb:

- prehľad platieb

- prehľad zvýraznených psov



Dizajn:

- moderný

- veľké fotky psov

- responzívny pre mobil aj počítač
